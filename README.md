# English Study Hub

A minimal, production-oriented Flask "landing page" scaffold for the Constellation project (Jira: CSTL-1). This repository implements a bare-bones landing page ("English Study Hub") using the Flask factory pattern, a Playwright screenshot helper, and a small pytest suite. This README documents setup, run, test, screenshot capture, and PR guidance.

Important source links
- Jira ticket: https://tarch.atlassian.net/browse/CSTL-1
- Stitch project (design reference): https://stitch.withgoogle.com/projects/13629074018280446337

Prerequisites
- Python 3.12 installed and available as python3.12
- Git
- Optional: Chrome / Chromium for Playwright screenshots (the Playwright install step will download browsers)

Local setup (recommended reproducible steps)
1. Clone the repository and create a feature branch:
   git clone https://github.com/fihtony/english-study-hub.git
   cd english-study-hub
   git checkout -b feature/CSTL-1_task-0001_final

2. Create and activate the Python 3.12 virtual environment:
   python3.12 -m venv .venv && . .venv/bin/activate

3. Install Python dependencies:
   pip install -r requirements.txt

4. Install Playwright browser binaries (required for the screenshot script):
   playwright install
   OR (explicit Python module invocation)
   python -m playwright install

Run the application
- Development / manual run:
  python run.py
  - The app reads the port from environment: PORT (default 5000).
    Example: PORT=8080 python run.py

- Access the landing page at:
  http://localhost:5000/

Notes about app structure and security
- The Flask app uses the factory pattern via app.create_app(config_object=None). Importing the package has no side-effects.
- Templates use Jinja2 auto-escaping; no untrusted input is rendered directly.
- Static assets are served from /static/ at the repository root (so /static/css/styles.css resolves regardless of working directory).
- run.py respects PORT via int(os.environ.get("PORT", 5000)) for compatibility with test harnesses and PaaS.

Running tests
- Ensure the virtualenv is activated and dependencies installed.
- Run:
  pytest -q

Test notes
- tests/test_factory.py: ensures create_app returns a Flask app and is side-effect free.
- tests/test_routes.py: uses app.test_client() (app.testing = True) to verify:
  - GET / returns HTTP 200 and contains "English Study Hub" and CTA "Get Started"
  - GET /static/css/styles.css returns HTTP 200, Content-Type contains "text/css", and includes CSS rules
- tests/test_acceptance_map.py: lightweight mapping to acceptance criteria for reviewer convenience.

Screenshot capture (Playwright)
- The included script scripts/capture_screenshots.py uses Playwright (Python sync API) to capture two responsive screenshots of the running site and save to:
  - docs/evidence/screenshot-1280x900.png
  - docs/evidence/screenshot-375x812.png

- Usage:
  1. Start the server: python run.py
  2. In another shell (same venv): python scripts/capture_screenshots.py
- If Playwright is not available in CI, run the screenshot capture locally. The script exits with non-zero on failure and prints helpful diagnostics.

Troubleshooting
- If pytest fails with import errors: ensure .venv is activated and Python 3.12 is used.
- If Playwright screenshot fails:
  - Confirm browsers were installed via playwright install
  - Ensure the server is running at the expected host/port (default http://localhost:5000)
  - Inspect printed traceback; the script exits non-zero and prints diagnostic messages

Developer notes and constraints
- This project targets Python 3.12 and Flask. The scaffold uses the Flask factory pattern to keep imports side-effect free and testable.
